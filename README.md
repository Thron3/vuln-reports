# Vulnerability Reports

Security vulnerability reports for open-source PHP applications, prepared for
submission to VulDB. All findings were verified on local instances
(127.0.0.1) against the current public downloads; no external system was
tested.

| # | Product | Vulnerability | Report |
|---|---------|---------------|--------|
| 1 | Computer Repair Shop Management System (PHP/OOP) 1.0 | Unauthenticated SQL Injection | [crsms/01](crsms/01-未授权SQL注入.md) |
| 2 | Product Expiry Monitoring System 1.0 | Unauthenticated Arbitrary Deletion | [product-expiry/01](product-expiry/01-未授权任意删除.md) |
| 3 | Church Management System | Unauthenticated Arbitrary File Deletion (Path Traversal) | [church/01](church/01-未授权任意文件删除.md) |

For coordinated disclosure contact the author via GitHub.
